# p11

מחשבון מטבע לימודי סטטי, בעברית. ברירת המחדל נשמרת מן המקור: 100 USD ל־ILS.

היישום קורא את Frankfurter v1 לפי base/symbols ומכפיל בסכום המקומי פעם אחת. השערים הם שערי ייחוס יומיים ולא מחיר תוך־יומי; תאריך השער מופיע בתוצאה. תיעוד: https://frankfurter.dev/v1/

להפעלה יש להגיש את index.html, script.js ו־mystyle.css מאותו שרת סטטי. אין package manager או build step במקור. כפתור ההמרה ו־Enter בשדה הסכום מפעילים המרה; שינוי בשדה הסכום/מטבע או pagehide מבטלים בקשה קודמת ומנקים תוצאה ישנה.

הקוד פוסל שדה ריק וסכום לא־סופי, מאמת מטבע מן הרשימה ותאריך ספק, ודוחה HTTP/schema לא תקינים; guard של nonfinite נבדק סטטית, בלי test amount נוסף. zero/negative אינם נאסרים ללא חוזה מוצר חדש. אין deadline אוטומטי: ביטול נעשה בבקשה חדשה, שינוי שדות או pagehide.

קבלה מוגבלת: בדיקות מבודדות משתמשות רק בברירת המחדל וב־API bytes אמיתיים שנשמרו; שגיאות transport/schema הן fault injection. המועמד אינו מוצר לפרסום לפני QA עצמאי ו־browser/provider acceptance. אין עסקאות, credentials או תמחור שירותים.
